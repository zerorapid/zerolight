# ZeroLight CLI (`zerolight`)

Token-driven B2B SaaS & ERP Design System CLI and Model Context Protocol (MCP) server by **Zerorapid**.

- Catalog & Docs: https://bricks.zerorapid.in
- LLM Reference: https://bricks.zerorapid.in/llms-full.txt
- Registry Index: https://bricks.zerorapid.in/r/index.json

## Quick Start

```bash
# Initialize ZeroLight tokens & context
npx zerolight init

# Add individual primitives or ERP blocks
npx zerolight add stat-card data-table approval-workflow three-way-match
npx zerolight add block/ledger-balancer
```

## MCP Server (Cursor, Claude Code, Antigravity)

```bash
npx zerolight-mcp
```
